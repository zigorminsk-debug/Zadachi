# Zadachi — учёт входящих звонков и заявок

Связка **Windows + Android** для приёма звонков: телефон и ПК в одной Wi‑Fi сети.

```
📱 Входящий звонок ──► телефон (только в разрешённой Wi-Fi) ──► всплывающее окно на ПК
                         ◄── номер из буфера обмена ПК (Ctrl+Alt+D) ── открывается звонилка
```

## Что умеет

**Windows** (`Zadachi.exe`, самодостаточный — Python/библиотеки на целевом ПК не нужны,
внутри только стандартная библиотека Python):

- работает в фоне, **стартует вместе с Windows** (HKCU Run), закрытие окна — в трей;
- при входящем звонке с телефона **сразу открывается заметка «Входящий звонок — новая задача»**:
  номер (или «Номер скрыт»), имя, текст заявки и таймер напоминания;
- заявки/задачи и звонки копятся в SQLite: база **`zadachi.db` лежит рядом с `Zadachi.exe`**
  и при замене/переустановке exe подхватывается автоматически (старая база из
  `%APPDATA%\Zadachi` при первом запуске новой версии сама перенесётся);
  при начале ввода **предлагаются** ранее введённые задачи, имена и телефоны (автоподсказки);
- напоминания всплывают поверх окон со звуком: «Готово» / «+10 минут» / позвонить;
  **двойной клик по задаче открывает её редактирование** (задача не исчезает;
  выполненной она помечается только кнопкой «✔ Выполнено»); по выделенной задаче
  кнопка **«📞 Позвонить по задаче»** отправляет её номер в звонилку телефона;
- **клик‑позвонить**: Zadachi регистрируется в Windows обработчиком ссылок `tel:`/`callto:` —
  клик по номеру-ссылке на любом сайте открывает звонилку телефона (при первом клике
  браузер/Windows может один раз попросить выбрать Zadachi; если Android запретит
  автоматический запуск звонилки, на телефоне останется уведомление «Набрать номер»).
  Номер, скопированный в любом
  месте Windows, предлагается кнопкой, а по **Ctrl+Alt+D** сразу уходит на телефон;
- сопряжение с телефоном по токену (показан во вкладке «Настройки»).

**Android** (`Zadachi.apk`, только Android SDK, без внешних библиотек):

- замечает входящие/пропущенные звонки и шлёт их на ПК, принимает с ПК команду
  «набрать номер» (открывает штатную звонилку — звонок подтверждает человек);
  для надёжного определения номера используется системная роль **«АОН и спам»**
  (`CallScreeningService`, включается кнопкой в приложении и ничего не блокирует),
  а имя подставляется из контактов телефона и из истории на ПК;
- **работает только в указанных вами Wi‑Fi сетях**: вне их сервис полностью
  остановлен и батарею не расходует; проверка сети — системным JobScheduler
  (≥15 мин, doze‑friendly), без опросов, сканирований и постоянных wakelock'ов;
- в активном режиме: один заблокированный сокет + системные события телефонии,
  wakelock ≤15 c только на отправку звонка;
- подписано **постоянным ключом** (`android/keystore/zadachi-release.keystore`),
  поэтому сборки с GitHub Actions ставятся обновлением одна поверх другой.

> **Запуск:** двойной клик по `Zadachi.exe` всегда открывает окно. В трей
> приложение уходит только при автозапуске с Windows (флаг `--tray`) и при
> закрытии окна кнопкой ✕. Если что-то пошло не так — подробности в
> `%APPDATA%\Zadachi\error.log`.

## Быстрый старт

1. Скачайте `Zadachi.exe` и `Zadachi.apk` из **Actions → последний Build → Artifacts**
   (или из Releases для тегов `v*`) и запустите/установите.
2. На ПК откройте вкладку «Настройки» — там токен сопряжения.
3. На телефоне: подключитесь к нужной Wi‑Fi → «Разрешить текущую сеть» → выдайте
   разрешения → введите токен с ПК → «Сохранить». IP ПК можно оставить пустым
   (кнопка «Найти ПК автоматически»).
4. Проверка: кнопка «Тест: тестовый звонок на ПК» в Android или просто позвоните
   на телефон — на ПК сразу откроется заметка для новой задачи. Для реальных
   звонков Android при первом открытии попросит доступ к телефону, журналу
   звонков и контактам: без них Android скроет номер, а имя не подставится.
   Дополнительно нажмите **«Включить определение номера входящих»** и
   выберите Zadachi как «АОН и спам» — это штатный способ Android показывать
   приложению настоящий номер звонящего (звонки не блокируются). В статусе
   должны быть «сервис запущен», доступы «есть» и определение номера
   «включено», а после звонка появится строка «Последний звонок».
5. В брандмауэре Windows разрешите для частной сети порты **TCP 39272** и **UDP 39271**.
6. Клик по номеру на сайте: Zadachi сама зарегистрируется обработчиком `tel:` при запуске.
   Если браузер при первом клике спросит, чем открыть ссылку, — выберите **Zadachi**
   («Всегда»). Если номер на странице — обычный текст, а не ссылка, скопируйте его
   и нажмите **Ctrl+Alt+D**.

> ⚠️ Пароль ключа подписи (`Zadachi2026!`, алиас `zadachi`) зашит в билд намеренно —
> так сборка на GitHub работает без секретов. Держите репозиторий приватным; для
> публичного — перенесите пароли в GitHub Secrets. Потеря ключа = нельзя обновлять
> установленное приложение, храните копию keystore отдельно.

## Сборка

Автоматически: любой push → GitHub Actions (`.github/workflows/build.yml`,
джобы Windows/Android параллельно, артефакты прикладываются к запуску; тег `v1.0.0`
создаёт Release). Вручную: ПК — `windows\build.bat`, Android — `cd android && gradlew.bat assembleRelease`.

Подробности: [архитектура и протокол](docs/ARCHITECTURE.md),
[энергопотребление Android](docs/BATTERY.md).

## Разработка

```bash
python -m unittest discover -s tests   # тесты ядра (без GUI)
cd windows && python Zadachi.py        # запуск из исходников (нужен Python 3.11+)
```

Значки приложений (`windows/icon.ico`, Android `mipmap-*`) сгенерированы из
одного исходника скриптом `tools/make_icons.py` (нужен Pillow только для
перегенерации; сами сборки работают по готовым файлам).

Структура: `windows/zadachi/` — приложение (БД, сервер, GUI, трей, автозагрузка),
`android/app/src/main/java/by/zadachi/calls/` — Android (MainActivity, CallService,
WifiGate, Net), `tests/` — юнит-тесты ядра.
