# Архитектура и протокол

## Компоненты

| Компонент | Технологии | Зависимости в рантайме |
|---|---|---|
| Windows | Python 3 stdlib: tkinter, sqlite3, http.server, ctypes (трей/hotkey/winreg) | нет (one-file .exe через PyInstaller на этапе сборки) |
| Android | Java, только Android SDK | нет (даже без AndroidX) |

## Протокол (локальная сеть, порты фиксированы)

| Канал | Порт | Что |
|---|---|---|
| UDP broadcast | 39271 | телефон шлёт `ZADACHI_DISCOVER_PC` → ПК отвечает JSON `{app, port}` |
| HTTP на ПК | TCP 39272 | `POST /api/call {event, number, device, ts}`, `POST /api/ping`, `GET /api/health` |
| HTTP на телефоне | TCP 39273 | `POST /dial {number}`, `POST /ping` |

Все POST требуют заголовок `X-Zadachi-Token: <токен сопряжения>`
(8 символов, генерируется на ПК при первом запуске). События звонков:
`incoming` (звонит), `missed` (пропущен), `ended` (завершён) и
`offline_reminder` (звонок вне сети, одобренный пользователем на телефоне:
`offline_id`, `remind_after_sec=300`, `repeat_mins=15`).

## Потоки данных

1. **Звонок → заявка.** Телефон (в разрешённой сети) → `/api/call` → ПК пишет
   журнал, поднимает popup: имя/заявка (автоподсказки из БД) + пресеты напоминаний
   (5 мин … сутки). Задача пишется в SQLite, имя связывается с номером.
2. **Напоминание.** ПК проверяет `tasks.remind_at` раз в 15 c собственными
   средствами (процесс и так в фоне) → popup поверх окон + звук.
3. **Позвонить с ПК.** Буфер обмена сканируется на номера (регулярка, 7–15 цифр);
   кнопка в toast или глобальный **Ctrl+Alt+D** → `POST /dial` на телефон →
   `ACTION_DIAL` в звонилке по умолчанию (звонок подтверждает пользователь).
4. **Звонок вне сети.** Вне разрешённых Wi-Fi `CallService` остановлен, но
   системный `PHONE_STATE` receiver и `CallScreeningService` запоминают звонок.
   После его завершения Android показывает «Напомнить / Отклонить». Выбранное
   напоминание хранится локально и отправляется при следующем появлении
   разрешённой сети; Windows создаёт задачу по `offline_id` без дублей,
   первое срабатывание — через 5 минут, повтор — каждые 15 минут до `done`.

## Фон Windows

- Автозагрузка: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Zadachi`.
- Закрытие окна сворачивает в трей (Shell_NotifyIconW через ctypes), сервер и
  таймеры продолжают работать; из трея — «Открыть / Новая задача / Выход».

## Безопасность

Протокол — только LAN. От чужих устройств в той же сети защищает токен;
номер нормализуется (`8 029 …` → `+37529…`) на обеих сторонах одинаково.
Поскольку ПК в локальной сети не имеет TLS-сертификата, Android-приложение
через `res/xml/network_security_config.xml` разрешает cleartext HTTP только
для своих запросов к заданному/найденному в LAN компьютеру (иначе Android
9+ блокирует соединение с ошибкой «Cleartext HTTP traffic not permitted»).
